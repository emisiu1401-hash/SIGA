# Seu SIGA

1. Abra **https://siga.emisiu1401.workers.dev**. A consulta de dados fictícios funciona também no celular.
2. Para gerir, clique em **Entrar na gestão**. Contas e senhas estão no arquivo privado **`.local/ACESSO_SIGA.md`**, nesta pasta do computador. Ele não foi publicado no GitHub.
3. Para inserir seu token OpenAI, entre como **Administrador** → **Configurações** → **Configurar token de IA**. O valor fica criptografado no servidor; em simulação não há consumo pago.
4. Como **Emerson · gestor**, crie demandas, atribua responsáveis, decida solicitações e use correspondência/simulador.

Repositório: **https://github.com/emisiu1401-hash/SIGA**.

O Gmail real requer OAuth próprio da aplicação. Nenhuma mensagem real foi enviada. Veja `docs/14_OPERACAO_DA_APLICACAO.md` e `docs/15_VALIDACAO_E_LIMITES.md`.
